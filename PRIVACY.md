# Mortgageusa Property Lookup – Privacy Policy

_Last updated: November 24, 2026_

Mortgageusa Property Lookup is an internal tool for Mortgageusa loan officers. It runs only on Mortgageusa's VICIdial agent screen (`mtgusa.talkitpro.com/agc/`) and on `www.homes.com`.

## What it reads
- The property address on the lead that is open in VICIdial (street, city, state, ZIP), plus the lead's loan amount and value fields.

## What it does with it
- It looks up that address on Zillow, Realtor.com, Trulia and Homes.com, and shows the public property details those sites return on the agent's screen.
- The address is sent only to those four sites, and only to look up the property.
- To search Homes.com, it opens a small Homes.com window that types in the address, reads the property page and closes itself.

## What it stores
- It keeps the current Homes.com lookup (the address and the details it found) in the browser's local extension storage on that computer, so the Vici window and the Homes.com window can pass the result to each other. Nothing is kept on any server.

## What it doesn't do
- It does not send any data to Mortgageusa, the developer or anyone other than the four property sites above.
- It has no analytics, tracking or advertising, and it does not sell or share data.
- It does not read any other website or any other part of the browser.

## Contact
Questions: contact Mortgageusa's IT or management team.
